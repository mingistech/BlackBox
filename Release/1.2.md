# BlackBox 1.2

BlackBox 1.2 adds portable API keys and improves the assistant and model picker.

- **Portable keys:** create an encrypted `BlackBox.keys` file beside the app on an external drive and unlock it with a passphrase when you launch. Optionally copy keys from this Mac’s Keychain; local Keychain storage remains available.
- **Autonomous mode:** clearer instructions encourage the assistant to run requested commands without asking in chat. Ask Before Command continues to use the app’s approval control.
- **Model suggestions:** the picker describes when to use each recommended OpenAI, Anthropic, and OpenRouter model; hover to see its model ID.

## Installation

Requires macOS 26.6 or later. The universal app supports Apple silicon and Intel, and is signed and notarized by Apple. Download the ZIP, unzip it, and move BlackBox to Applications or your external drive. API usage is billed by your provider.

For portable keys, open **Settings → Portable Keys…** and save `BlackBox.keys` next to `BlackBox.app`. Keep both files together and back up the key file; a lost passphrase cannot be recovered. Preferences such as the selected model remain per Mac. If macOS opens the app from a temporary location, use **Open Key File…** to select the file on your drive.
