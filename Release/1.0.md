# BlackBox 1.0

The first release of BlackBox: a native macOS terminal with an AI assistant for local command-line tasks and remote SSH troubleshooting.

- A real local terminal and SSH session, with an assistant that reads output and helps run commands.
- Direct OpenAI and Anthropic support, plus OpenRouter, with API keys stored separately in macOS Keychain.
- Manual, Ask Before Command, and Autonomous modes.
- Model selection beside the prompt, with starred favorites and provider setup indicators.
- Return to send, Shift-Return for multiline prompts, and Up/Down prompt history that preserves multiline navigation.
- Native Settings access through Command+, and the BlackBox menu.

## Requirements and installation

macOS 26.6 or later. Universal app for Apple silicon and Intel Macs.

Download `BlackBox-1.0-macOS.zip`, unzip it, and move BlackBox into Applications. Add your API key in Settings to use the assistant. API usage is billed by your provider.

## Before you start

Assistant requests include chat and terminal context sent to your selected AI provider. Enter passwords in the terminal, never in chat. Chat and prompt history are kept in memory for the current app session. SSH connection and command-completion indicators are best-effort observations.
