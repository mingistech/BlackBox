# BlackBox 1.1

BlackBox 1.1 updates its direct-provider model selection for local and remote terminal work.

- OpenAI: GPT-6 Astra, GPT-6.1 Sol, GPT-6.1 Terra, and GPT-6 Luna.
- Anthropic: Sonnet 5.5, Fable 5.2, Opus 5.5, and Haiku 5.5.
- Previous selections and favorites migrate to corresponding supported models where possible.
- Updated reasoning settings and conversation handling for the new models. OpenRouter remains available.

Requires macOS 26.6 or later. The universal app supports Apple silicon and Intel, and is Developer ID signed and notarized by Apple. Download the ZIP, unzip it, and move BlackBox to Applications. API access and billing depend on your provider.
